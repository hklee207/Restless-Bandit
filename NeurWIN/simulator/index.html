EV charging as a restless bandit: Whittle index vs NeurWIN

A charging station has N spots but only enough power to charge M cars per round. When a car arrives at an empty spot it announces how many rounds until it leaves (T) and how many units of charge it needs (B). The station earns 1 − c = 0.5 for each unit it charges, and pays 0.2 × B² for the charge still missing when a car leaves. Each spot is one “arm”: every round the station scores each spot with an index and charges the top M. Below, two copies of the same station see exactly the same cars arrive. Only the index differs.
